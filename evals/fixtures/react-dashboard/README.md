# 📊 Dashboard App

A modern, responsive dashboard built with React and TypeScript. ✨

## 🚀 Features

- **Real-time Stats**: Comprehensive overview of your key metrics
- **Smart Notifications**: Seamless notification management with unread badges
- **Persistent Preferences**: Your selected date range is saved to localStorage

## 🛠️ Getting Started

1. Install the dependencies: `npm install`
2. Run the type checker: `npm run typecheck`
3. Run the test suite: `npm test`
